# learning

## Lyric Rhyme & Rhythm Analyzer

A Python tool for analyzing rhyme schemes, syllable counts, and rhythm patterns in English and Chinese lyrics.

### Setup

```bash
pip install -r requirements.txt
```

### Usage

```bash
python lyric_analyzer.py
```

The analyzer provides:
- **English rhyme detection** via CMU Pronouncing Dictionary
- **Chinese rhyme analysis** using 十三辙 (Shísān Zhé) rhyme groups
- **Syllable counting** for rhythm/meter analysis
- **Rhyme scheme labeling** (A-B-B-A, A-B-C-A-B-C, etc.)
